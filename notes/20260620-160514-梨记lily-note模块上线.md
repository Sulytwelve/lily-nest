## 这是什么？

一句话：**梨窝现在可以写笔记了。**

每篇笔记就是一个 Markdown 文件，放在 `notes/` 文件夹里。

至于数据库？以后会根据规模加到SQLite，再大些会改为PostgreSQL。

## 为什么做

梨梨因为觉得之前维护的太长了，是时候要加新功能了，但是因为没时间，所以用了多种AI进行代码生成，虽然梨梨还是心有余悸。但至少整体框架是梨梨想出来的，并不断纠正。不然就不会像这样，搞了好几天就一个新功能。肯定是斟酌过的啦。

- 想扩展应用面
- 同时有个课程需要

## 怎么用

- 在管理后台写，或者直接把 `.md` 文件丢进 `notes/`
- 在 `梨窝` 首页点击 `梨记` 按钮即可看笔记列表
- 点进去就是渲染好的页面
- 顶部的搜索框可以搜标题和标签

## 写代码长这样

下面是一段 Rust 代码，markdown 渲染出来自带格式：

```rust
fn main() {
    let note = "hello, lily-note!";
    println!("📝 {note}");
}
```
