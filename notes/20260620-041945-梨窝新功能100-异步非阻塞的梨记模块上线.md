欢迎来到「梨记」！ 🎉                                                                                                                           
                                                                                                                                                  
  这是梨窝 (lily-nest) 刚刚上线的一个轻量级笔记模块。它的设计初衷是**「够用就好」**，抛弃了复杂的数据库，一切内容皆以 Markdown 纯文本文件存在。   
                                                                                                                                                  
  ### 核心特性                                                                                                                                    
                                                                                                                                                  
  1. 纯文件驱动：所有的笔记保存在  notes/  目录下。没有 MySQL，没有 Redis，只有最纯粹的  .md  文件。
  2. 极速前端检索：通过原生 JavaScript 实现的纯前端搜索，输入关键词或  #标签  即可瞬间过滤笔记。
  3. 原生管理后台：直接在网页端创建和更新笔记，所有改动实时落盘。
  4. 100% 异步非阻塞：底层的  note_loader  已经彻底重构为  async 。无论是应用启动扫描，还是管理端的 CRUD 操作，全部基于  tokio::fs  实现，彻底告别
  Tokio 线程阻塞。
