## 🎉 欢迎来到梨窝笔记系统

你现在看到的这篇内容，完全是由 **Markdown** 加上 **TOML Frontmatter** 驱动的。
它不再被生硬地塞进 JSON 或 TOML 的字符串里，你可以自由地在这里编写多行文本、使用列表，或者贴上优美的代码块：

```rust
fn main() {
    println!("Hello, lily-nest notes!");
}
```

### 为什么采用这种架构？

1. **零内存浪费**：系统启动时，仅仅扫描了这篇文档头部的 `---` 区域，将标题、标签、时间和摘要装载到内存索引中，正文静静地躺在硬盘里。
2. **LRU 按需渲染**：当你第一次访问 `/note/hello-notes` 时，系统瞬间将下方的 Markdown 解析为 HTML，并装载到 LRU 缓存池中。
3. **SEO 友好**：爬虫抓取这个页面时，拿到的是纯正无污染的 HTML 标签，而不是等待 JS 执行的一坨骨架屏。
